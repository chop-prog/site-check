# Проверка сайта

Вводите адрес и получаете отчёт простыми словами: что мешает клиентам и поисковикам и что исправить в первую очередь. Готовый текст можно отправить владельцу сайта.

_English: a local tool that checks a website's front page and explains the problems to its owner in plain words._

```bash
node server.mjs   # http://localhost:8784
npm test
```

## Как устроено

- [`src/report.js`](src/report.js) разбирает HTML страницы и составляет список проблем по важности: мобильная версия, HTTPS, заголовки, запрет индексации, кликабельный телефон, мессенджеры. Функции чистые и покрыты тестами.
- [`server.mjs`](server.mjs) — маленький сервер без зависимостей. Браузер не может читать чужие сайты сам, поэтому страницу скачивает он. Слушает только этот компьютер.

## Ограничения

Проверяются главная страница и её исходный код. Если сайт собирается скриптами в браузере, отчёт об этом предупреждает и не судит о содержимом. Скорость показана как время ответа сервера с вашего компьютера.
